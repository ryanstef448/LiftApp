# Lift Off
App to track nutrition and lifting progress.

## Running the Application

The project consists of two parts:
1. **Backend Server** (Express + SQLite): runs on `http://localhost:3001`
2. **Frontend Client** (React + Vite): runs on `http://localhost:5173`

You need **two terminal windows** open:

### Terminal 1: Start Backend Server
```bash
cd server
npm start
```
*(Or from the project root: `npm run server`)*

The backend will start at: `http://localhost:3001`

### Terminal 2: Start Frontend Client
```bash
cd client
npm run dev
```
*(Or from the project root: `npm run client`)*

The frontend will start at: `http://localhost:5173`

### Accessing the App
Open your web browser and navigate to:
👉 **[http://localhost:5173](http://localhost:5173)**
